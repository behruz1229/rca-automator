# RCA Automator — автоматическая выгрузка инспекций

Консольная утилита для автоматического формирования и выгрузки отчёта по инспекциям (RFI, строительный контроль, металлические конструкции) из системы АИС НСК (RCA) в Excel с сохранением файла в сетевую папку.

Написано на Go с использованием библиотеки [go-rod](https://github.com/go-rod/rod) (управление браузером через Chrome DevTools Protocol).

## Что делает скрипт

1. Выполняет вход в систему RCA по данным из `config.txt`.
2. Переходит на страницу задач строительного контроля.
3. Открывает диалог «Фильтрация по параметрам» и применяет условия:
   - марка комплекта — **км** (выбирается «(КМ) Конструкции металлические»);
   - тип заявок — **RFI (строительный контроль)**;
   - поле даты очищается;
   - поиск — **SMU**.
4. Нажимает кнопку «Выгрузка в Excel».
5. Ожидает скачивания файла `Инспекции на <дата>.xlsx` (до 5 минут — время зависит от скорости ответа сервера).
6. Удаляет в целевой сетевой папке старые файлы `Инспекции на*.xlsx` (в папке всегда остаётся только один актуальный файл).
7. Копирует новый файл в сетевую папку из `config.txt` и удаляет локальную копию из «Загрузок».

## Требования

- Windows 10/11;
- [Go](https://go.dev/dl/) 1.21 или новее;
- установленный Google Chrome или Microsoft Edge (браузер находится автоматически);
- учётная запись RCA и доступ к целевой сетевой папке.

## Установка и запуск

```bash
# клонируйте репозиторий
git clone https://github.com/ВАШ_ЛОГИН/rca-automator.git
cd rca-automator

# создайте файл конфигурации и заполните своими данными
copy config.example.txt config.txt

# соберите и запустите
go mod tidy
go build -o RCA_Auto.exe
RCA_Auto.exe
```

## Настройка config.txt

| Параметр       | Описание                                      |
|----------------|-----------------------------------------------|
| `login`        | ваш логин для входа в RCA                     |
| `password`     | ваш пароль для входа в RCA                    |
| `network_path` | сетевая папка для сохранения выгрузки         |

Пример заполнения:

```
login=ivanov.ab
password=secret
network_path=\\server\share\папка\Выгрузки
```

> ⚠️ Файл `config.txt` содержит учётные данные и добавлен в `.gitignore` — он никогда не попадёт в репозиторий. Не публикуйте его вручную.

## Примечания

- **Фоновый режим.** По умолчанию браузер работает скрыто (headless). Чтобы окно браузера было видно, замените в `main.go` строку `Headless(true)` на `Headless(false)`.
- **Папка загрузок.** Файл скачивается в стандартную папку «Загрузки» текущего пользователя (определяется автоматически), затем переносится в сетевую папку; локальная копия удаляется.
- **Логи и отладка.** При каждом запуске файл `debug.log` перезаписывается. При ошибке в папке скрипта создаётся скриншот `error_<шаг>.png`; старые скриншоты удаляются при старте автоматически.
- **Ожидание скачивания.** Скрипт отслеживает фактическое появление файла в папке загрузок, а не ждёт фиксированную паузу, поэтому корректно работает и при быстрой (30 сек), и при долгой (5 мин) генерации отчёта.
