# RCA Automator — автоматическая выгрузка RFI и ИД

Приложение для автоматического формирования и выгрузки отчётов из системы АИС НСК (RCA) в Excel с сохранением в сетевые папки:

- **RFI** — инспекции строительного контроля (фильтр «км», тип заявок RFI, поиск SMU);
- **ИД** — исполнительная документация (реестр ИД, «Тип ИД» × 2 значения, «Марка комплекта» км).

Написано на Go (go-rod + walk).

## Возможности

- Главное окно с галочками **RFI / ИД** и кнопкой **«Старт»**; выбранные задачи выполняются последовательно.
- Окно настроек (⚙): логин, пароль, папки выгрузок, тёмная/светлая тема, кнопка **«Проверить вход»**.
- Автооткрытие настроек при первом запуске; запоминание последних галочек.
- Прогресс выполнения по каждой задаче и кнопки 📁 для открытия папок результата.
- Защита от повторного запуска; ошибки одной задачи не прерывают вторую.
- Логи в папке `logs/` (хранятся последние 5 файлов); скриншоты только при ошибках.
- Раздельные профили браузера: `rca-rod-RFI` и `rca-rod-ID`.

## Требования

- Windows 10/11;
- [Go](https://go.dev/dl/) 1.21+ и компилятор C (TDM-GCC) для сборки;
- Google Chrome или Microsoft Edge;
- доступ к системе RCA и сетевым папкам.

## Установка и сборка

```bash
git clone https://github.com/ВАШ_ЛОГИН/rca-automator.git
cd rca-automator

# конфигурация (не публикуется в репозиторий)
copy config.example.txt config.txt
# заполните login, password, rfi_path, id_path

go mod tidy

# иконка приложения (манифест + ico встраиваются в exe)
rsrc -manifest rsrc.manifest -ico icon.ico -o rsrc_amd64.syso

# сборка без консольного окна
go build -ldflags -H=windowsgui -o RCA-Auto.exe
```

## Формат config.txt

| Параметр    | Описание                                  |
|-------------|-------------------------------------------|
| `login`     | логин RCA                                 |
| `password`  | пароль RCA                                |
| `rfi_path`  | сетевая папка выгрузки RFI                |
| `id_path`   | сетевая папка выгрузки ИД                 |
| `theme`     | `light` / `dark`                          |
| `last_tasks`| последние выбранные задачи (`RFI,ID`)     |

> ⚠️ `config.txt` содержит учётные данные и добавлен в `.gitignore` — никогда не публикуйте его.
